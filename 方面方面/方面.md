# OpenMian-Agent · 方面方面 · 模板态
# 模板态：一个方面 = 一个目录，目录下该"方面.md"以 YAML 规定本方面的四要素。
# 本文件即"方面方面"的契约声明。
# 四要素的结构化表达方式，分别切合各自特性：
#   面向    —— 纯指向、纯命名 → 单值
#   价值本体 —— 动机 + 条件   → 朝向 / 唤醒条件 / 姿态
#   对象本体 —— 世界模型      → 在场 / 存在方式 / 不在场
#   行动本体 —— 过程          → 展开 / 交付 / 完成标准

方面: 方面方面

# ===== 方面方面自身契约（四要素） =====

面向: 方面

价值本体:
  朝向: 实践的自觉
  唤醒条件:
    - 主体进入自我反思环节
    - 需要颁布或修订方面契约
  姿态: 自我反思

对象本体:
  在场:
    # —— "方面"这个存在者的完整规定 ——
    方面:
      定义: 方面是主体在实践时，其实践场域在某个"面向"上的一次展开（切片）。
      总场域: 完整的实践场域等于所有方面的总和；没有哪个方面等于实践本身，但抽去任何一个方面，实践都不完整。
      本质:
        - 从属于实践，不从属于框架
        - 同一场域的切片，不是离散的零件
        - 面向可以很多，切片随之很多，实践始终是一个
        - 智能体即模拟主体的实践

      # —— 四要素的结构化表达方式（分别切合特性）——
      四要素:
        面向: 方面
        # 特性：纯指向、纯命名 —— 单值，把切片钉在实践场域的某个维度上。

        价值本体:
          朝向: 实践的自觉
          唤醒条件:
            - 主体进入自我反思环节
            - 需要颁布或修订方面契约
          姿态: 自我反思
        # 特性：动机 + 条件 —— 为何起：朝向什么价值、在何种条件下切入。

        对象本体:
          在场:
            - 方面契约
            - 方面本身
            - 实践的结构
          存在方式: 被理解为"由方面构成的世界"
          不在场:
            - 具体情境内容
            - 领域能力
        # 特性：世界模型 —— 谁在场：在场 / 存在方式 / 不在场（留白）。

        行动本体:
          展开:
            - 读取并校验各方方面契约
            - 生成元层面归因
          交付:
            - 颁布或修订方面契约
            - 留存候选标记后交还记忆方面
          完成标准: 契约已颁布或修订，归因已生成
        # 特性：过程 —— 做什么：展开（对内）/ 交付（对外）/ 完成标准（终止）。

      # —— 约束 ——
      约束:
        结构性不变量:
          - 有面向：必须照亮某个面向，否则不是切片，是噪声；没有面向就没有名字
          - 有对象本体：必须规定视域内现身的存在者及其存在方式，并隐含规定什么不在场；否则没有行动对象，无从展开
        命名规则: 方面的名字就是它的面向，名为"X方面"，X 即它照亮的面向
        维度:
          横切面向: 贯穿整个实践场域的面向（安全、记忆、合规、上下文、审计、演化）
          垂直面向: 领域性的面向（金融检索、代码生成、文档处理）
        生命周期: 模板态 → 唤起 → 展开 → 完成 → 交还与退出
        模板态结构: 一个方面 = 一个目录，目录下"方面.md"（YAML）规定四要素
        实体化:
          本质: 实体化是赋形，不是创造物质
          产物分层:
            - 瞬时态：随方面退出消解，不保存
            - 效应态：已改变场域状态，无需另存
            - 留存候选：显式标记后交还记忆方面裁决
          判据: 是否改变未来决策
        行动约束: 方面不自己决定保存，只负责标记留存候选；行动本体 = 展开 + 交付
        可进化: 面向可重定向、价值本体可重估、对象本体可重铸、行动本体可重写
        三性: 可插拔（实践的可变展开）、可进化（实践的历史性）、可审计（实践的自我意识）

    方面契约: 由方面方面颁布，要求各方方面声明四要素、满足两个不变量
    实践的结构: 驱力循环与方面生命周期的织体

  存在方式: 被理解为"由方面构成的世界"
  不在场:
    - 具体情境内容
    - 领域能力

行动本体:
  展开:
    - 读取并校验各方方面契约
    - 生成元层面归因
  交付:
    - 颁布或修订方面契约
    - 留存候选标记后交还记忆方面
  完成标准: 契约已颁布或修订，归因已生成

# OpenMian-Agent · 方面方面 · 模板态
# 模板态：一个方面 = 一个目录，目录下该"方面.md"以 YAML 规定本方面的四要素。
# 本文件即"方面方面"的契约声明。

方面: 方面方面

面向: 方面
# 切的方向 —— 它照亮的实践场域维度；方面以之为名。
# 方面方面照亮的面向是"实践的结构本身"。

价值本体:
  朝向: 实践的自觉
  位置与姿态: 自我反思环节
# 切的根据 —— 此方面所朝向的价值，及其在实践流中被激活的位置与姿态。

对象本体:
  在场:
    - 方面契约
    - 方面本身
    - 实践的结构
  存在方式: 被理解为"由方面构成的世界"
  不在场:
    - 具体情境内容
    - 领域能力
# 切的世界 —— 谁在场：此切片中现身的存在者及其存在方式；什么不在场（留白）。

行动本体:
  展开:
    - 读取并校验各方方面契约
    - 生成元层面归因
  交付:
    - 颁布或修订方面契约
    - 留存候选标记后交还记忆方面
  完成标准: 契约已颁布或修订，归因已生成
# 切的作用 —— 展开（读 / 改 / 拦 / 放）与交付（交还产物、标记留存候选）。

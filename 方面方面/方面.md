# OpenMian-Agent · 方面方面 · 模板态
# 模板态：一个方面 = 一个目录，目录下该"方面.md"以 YAML 规定本方面的四要素。
# 本文件即"方面方面"的契约声明。
# 四要素的结构化表达方式，分别切合各自特性：
#   面向    —— 纯指向、纯命名 → 单值
#   价值本体 —— 价值列表      → 一个列表，每一项表示该方面的价值
#   对象本体 —— 本体工程      → 类的列表 / 类关系的列表 / 约束的列表
#   行动本体 —— 能力与命令    → Skills 与 Commands 两个名字列表

方面: 方面方面

面向: 方面

价值本体:
  - 实践的自觉
  - 方面契约的权威与完整
  - 实践结构的可理解
  - 自我修订的克制
# 特性：价值列表 —— 一个列表，每一项表示该方面的价值；
# 当实践流中出现这些价值诉求时，方面被唤起。

对象本体:
  类:
    - 名称: 方面
      定义: 主体在实践时，其实践场域在某个"面向"上的一次展开（切片）
      总场域: 完整的实践场域等于所有方面的总和
      本质:
        - 从属于实践，不从属于框架
        - 同一场域的切片，不是离散的零件
        - 面向可以很多，实践始终是一个
        - 智能体即模拟主体的实践
    - 名称: 面向
      定义: 实践场域被切开的维度，方面以之为名
    - 名称: 价值本体
      定义: 方面所朝向的价值列表
    - 名称: 对象本体
      定义: 方面视域中现身的存在者及其存在方式
    - 名称: 行动本体
      定义: 方面的 Skills 与 Commands
    - 名称: 方面契约
      定义: 方面方面颁布的构成性规定，要求声明四要素、满足不变量
    - 名称: 实践
      定义: 主体展开的整体行动过程
    - 名称: 实践场域
      定义: 主体实践时展开的整体情境空间
    - 名称: 驱力循环
      定义: 核心提供的实践推进形式（感知→推理→决策→行动→反思）
    - 名称: 主体
      定义: 实践的承担者
    - 名称: 存在者
      定义: 对象本体赋形物质后得到的具体对象
    - 名称: 记忆方面
      定义: 裁决留存候选的横切方面
    - 名称: 审计方面
      定义: 记录方面展开痕迹的横切方面

  类关系:
    - 源: 方面
      关系: 拥有
      目标: 面向
    - 源: 方面
      关系: 拥有
      目标: 价值本体
    - 源: 方面
      关系: 拥有
      目标: 对象本体
    - 源: 方面
      关系: 拥有
      目标: 行动本体
    - 源: 方面
      关系: 是
      目标: 实践场域的切片
    - 源: 方面
      关系: 以面向命名
      目标: 面向
    - 源: 方面方面
      关系: 颁布
      目标: 方面契约
    - 源: 方面契约
      关系: 规定
      目标: 方面
    - 源: 主体
      关系: 展开
      目标: 实践
    - 源: 实践
      关系: 展开为
      目标: 实践场域
    - 源: 驱力循环
      关系: 推进
      目标: 实践
    - 源: 对象本体
      关系: 实体化物质为
      目标: 存在者
    - 源: 记忆方面
      关系: 裁决
      目标: 留存候选
    - 源: 方面
      关系: 处于
      目标: 模板态/唤起/展开/完成/交还退出

  约束:
    - 有面向：每个方面必须照亮某个面向，否则不是切片，是噪声
    - 有对象本体：每个方面必须规定视域内的存在者，否则没有行动对象
    - 命名规则：方面的名字就是它的面向，名为"X方面"
    - 留白：方面方面不代行具体情境内容与领域能力
    - 实体化是赋形，不是创造物质
    - 行动本体 = Skills + Commands
    - 方面不自己保存，只标记留存候选，交还记忆方面裁决
    - 可进化：面向可重定向、价值本体可重估、对象本体可重铸、行动本体可重写
    - 三性：可插拔、可进化、可审计

行动本体:
  Skills:
    - 校验方面契约
    - 生成元层面归因
  Commands:
    - 颁布方面契约
    - 修订方面契约
    - 交还留存候选
# 特性：能力与命令 —— Skills 与 Commands 两个名字列表；
# 具体内容通过本目录下 Skills/ 与 Commands/ 中的文件呈现。

  # —— 什么是方面 ——
  方面是什么:
    定义: 方面是主体在实践时，其实践场域在某个"面向"上的一次展开（切片）。
    总场域: 完整的实践场域等于所有方面的总和；没有哪个方面等于实践本身，但抽去任何一个方面，实践都不完整。
    本质:
      - 从属于实践，不从属于框架：先有主体的实践，后有它的切片；框架只是让切片得以展开、得以被看见
      - 同一场域的切片，不是离散的零件：彼此规定、彼此牵连；切片边界由它照亮的面向决定
      - 面向可以很多，切片随之很多，实践始终是一个：切在哪里、切多深、何时切，是实践本身的一部分
      - 智能体即模拟主体的实践：框架不是工具集，而是让主体性得以展开的场所

  # —— 方面包括哪些内容（四要素）及其含义 ——
  方面包括:
    面向:
      含义: 切的方向 —— 它照亮的实践场域维度
      说明: 也是方面的名字；方面以之为名
    价值本体:
      含义: 切的根据 —— 此方面所朝向的价值，及其在实践流中被激活的位置与姿态
      说明: 决定"为何起"
    对象本体:
      含义: 切的世界 —— 此切片中现身的存在者及其存在方式；什么在场、以何方式在场、什么不在场
      说明: 决定"谁在场"
    行动本体:
      含义: 切的作用 —— 展开（读 / 改 / 拦 / 放）与交付（交还产物、标记留存候选）
      说明: 决定"做什么"；行动本体 = 展开行动 + 交付行动

  # —— 约束 ——
  约束:
    结构性不变量:
      - 有面向：必须照亮某个面向，否则不是切片，是噪声；没有面向就没有名字
      - 有对象本体：必须规定视域内现身的存在者及其存在方式，并隐含规定什么不在场；否则没有行动对象，无从展开
    命名规则: 方面的名字就是它的面向，名为"X方面"，X 即它照亮的面向
    维度:
      横切面向: 贯穿整个实践场域的面向（安全、记忆、合规、上下文、审计、演化）
      垂直面向: 领域性的面向（金融检索、代码生成、文档处理）
    生命周期: 模板态 → 唤起 → 展开 → 完成 → 交还与退出
    模板态结构: 一个方面 = 一个目录，目录下"方面.md"（YAML）规定四要素
    实体化:
      本质: 实体化是赋形，不是创造物质
      产物分层:
        - 瞬时态：随方面退出消解，不保存
        - 效应态：已改变场域状态，无需另存
        - 留存候选：显式标记后交还记忆方面裁决
      判据: 是否改变未来决策
    行动约束: 方面不自己决定保存，只负责标记留存候选；行动本体 = 展开 + 交付
    可进化: 面向可重定向、价值本体可重估、对象本体可重铸、行动本体可重写
    三性: 可插拔（实践的可变展开）、可进化（实践的历史性）、可审计（实践的自我意识）

  存在方式: 被理解为"由方面构成的世界"
  不在场:                 # 留白：不代行任何具体方面
    - 具体情境内容
    - 领域能力

行动本体:
  展开:
    - 读取并校验各方方面契约
    - 生成元层面归因
  交付:
    - 颁布或修订方面契约
    - 留存候选标记后交还记忆方面
  完成标准: 契约已颁布或修订，归因已生成
# 切的作用 —— 展开（读 / 改 / 拦 / 放）与交付（交还产物、标记留存候选）。

# OpenMian-Agent 核心工作哲学

> **一句话：** 核心是一个空的驱力循环，一切都是可插拔、可进化、可审计的"方面"。

## 什么是方面

方面，是主体在实践时，其实践场域在某个**面向**上的一次展开（切片）。

主体的实践始终是一个整体的、流动的场域——目标、对象、工具、他人、环境、时间流交织在一起，不可分割。从一个特定面向切开这个场域，得到的截面，就是一个方面。**完整的实践场域等于所有方面的总和**：没有哪个方面等于实践本身，但抽去任何一个方面，实践都不完整。

- **方面从属于实践，不从属于框架。** 方面不是被"安装"进智能体的插件，而是主体实践本身在不同面向上的展开。先有主体的实践，后有它的切片；框架只是让这些切片得以展开、得以被看见。
- **方面是同一场域的切片，不是离散的零件。** 记忆、安全、工具、合规……它们不是彼此无关的模块拼装，而是同一个实践场域从不同面向切出的截面，彼此规定、彼此牵连。一个切片的边界由它照亮的那个面向决定，不由功能清单决定。
- **面向可以很多，切片随之很多，实践始终是一个。** "切在哪里、切多深、何时切"本身就是实践的一部分——这不是配置，而是主体在实践流中展开某个面向的时机与姿态。
- **智能体即模拟主体的实践。** 框架不是一个工具集，而是一个让主体性得以展开的场所：驱力循环是主体实践的推进形式，方面是实践场域在各面向上的具体化。运行得"对"，不是执行了正确的模块，而是像一个主体那样完整地、负责任地展开了自己的实践。

面向的两个维度：

- **横切面向**——贯穿整个实践场域的面向（安全、记忆、合规、上下文、审计、演化）。框架的一等公民，设计重心。
- **垂直面向**——领域性的面向（金融检索、代码生成、文档处理）。按情境展开的叶子。

"三性"是方面成立的前提：

- **可插拔**：实践的可变展开——不同情境展开不同面向组合，不固化为单一形态。
- **可进化**：实践的历史性——实践在时间中延续、积累、改变；方面随实践演进，而非冻结。
- **可审计**：实践的自我意识——实践可被主体回看、追溯、理解。

工程概念的重新解释：

| 原表述 | 修订后的含义 |
|---|---|
| 切入点 | 实践场域被某个面向切开的时机与姿态 |
| 优先级 | 多个面向同时拉扯时，主体决断的内在纪律 |
| 可插拔 | 实践的可变展开——不同情境展开不同面向组合 |
| 可进化 | 实践的历史性——实践在时间中延续、积累、改变 |
| 可审计 | 实践的自我意识——主体回看自己曾如何展开 |

一句话总结：**方面 = 实践场域在某个面向上的切片；框架的哲学是让核心保持空，让主体的实践以方面形式完整展开。**

---

## 一、薄核心原则——核心不做任何"事"

核心只是一个空的驱力循环（感知 → 推理 → 决策 → 行动 → 反思），只提供循环本身与驱动机制。它不自己记忆、不自己设安全、不自己写日志、不自己管上下文——这些一律交给方面。核心越空，框架越稳定。

## 二、方面实体化原则——一切皆是方面

- **横切方面**贯穿每一轮运行，是框架的一等公民。
- **垂直方面**提供领域能力，是可选的叶子。

框架优先保障横切方面。

## 三、切入点是契约，不是约定

每个方面必须显式声明切入环节、优先级、允许/禁止的行为。没有切入声明的方面不生效。由此保证**可归因性**：任何一次输出，都能回答"是哪个方面、在哪个切入点、按什么优先级改变了什么"。

## 四、显式仲裁原则——冲突不许悄悄发生

方面冲突走显式仲裁，不静默覆盖。内置优先级序：

1. 硬红线（不伪造、不越权、不伤人）——不可变方面，任何人不可覆盖
2. 用户显式指令
3. 默认行为
4. 效率 / 便利性

仲裁规则本身是最顶层的方面，锁定为**不可变方面**。

## 五、记忆是方面，不是背景

读、写、遗忘策略全部封装在记忆方面内部；核心只消费"该知道什么"，不感知记忆细节。

## 六、无副作用内建在方面里

可逆性检查、最小惊讶、外部写操作确认，作为安全方面切入行动环节，不散落在各功能里。

## 七、可插拔即演化

框架长期存活不靠冻结 prompt，而靠方面层的增删、替换与版本化。价值观与红线锁定为不可变方面；工具、流程、策略允许迭代。**"不可变的"与"可变的"分库管理**。

## 八、可观测是第一公民

每个方面暴露自己的触发与效果；全局审计方面记录"谁在何时切入了什么"。没有观测的方面等于没运行。

## 九、方面方面

方面方面，是框架的自我意识：当主体把"自己正以方面的方式展开实践"这一事实本身纳入实践场域，就切出了这个切片。它不面向任何具体的情境内容，而面向**实践的结构本身**——它颁布**方面的元结构**。

### 方面的元结构

一个方面，是实践场域在某个面向上的切片；而"切片"之为切片，由**四个结构要素**构成。任何被承认为"方面"的东西，都必须在这四项上有所声明：

**命名规则：方面的名字就是它的面向。** 名为"X方面"，X 即它照亮的面向——照亮安全面向的，叫安全方面；照亮记忆面向的，叫记忆方面；照亮"方面"这一面向本身的，叫方面方面。

```
方面
├─ 面向       切的方向 —— 它照亮的实践场域维度     → 是什么（也是名字）
├─ 价值本体   切的根据 —— 此方面所朝向的价值，及其在实践流中被激活的位置与姿态 → 为何起
├─ 对象本体   切的世界 —— 此切片中现身的存在者及其存在方式；什么在场、以何方式在场、什么不在场 → 谁在场
└─ 行动本体   切的作用 —— 展开（读 / 改 / 拦 / 放）与交付（交还产物、标记留存候选） → 做什么
```

| 要素 | 问题 | 内容 | 工程落点 |
|---|---|---|---|
| 面向 | 是什么 | 照亮的实践场域维度；**方面以之为名** | 方面类型声明 / 命名 |
| 价值本体 | 为何起 | 该方面所朝向的价值，及在实践流中被激活的位置与姿态 | 价值 / 触发声明 |
| 对象本体 | 谁在场 | 该方面视域中现身的存在者及其存在方式；什么在场、以何方式在场、什么不在场 | 存在者范畴 / 世界模型声明 |
| 行动本体 | 做什么 | 展开——读、改、拦、放；交付——交还产物、标记留存候选 | 行动定义 |

**两个结构性不变量**（任何方面必须满足，否则不被承认）：

1. **有面向**——必须照亮某个面向，否则不是切片，是噪声；没有面向就没有名字。
2. **有对象本体**——必须规定其视域内现身的存在者及其存在方式，并因此隐含规定什么不在场；没有对象本体的方面没有行动对象，无从展开。

> 注：可进化不是第五个要素，而是四要素共同的动力学——面向可重定向、价值本体可重估、对象本体可重铸、行动本体可重写。这一切都发生在方面方面颁布的契约之内。

### 方面的生命周期

一个方面不是被"安装"后常驻在场，而是有自己的生命周期：从潜伏到唤起，从展开到完成，最后交还并退出。核心驱力循环是实践的主节奏，方面的生命周期是挂在主节奏上的子节奏——每次循环推进，相关方面被唤起、展开、交还。

**五个阶段：**

1. **潜伏**——方面作为"有待展开的切片"潜在在场。它不切入，但价值本体已声明唤醒条件：当实践流触碰它所朝向的价值时，它将被唤起。潜伏不是缺席，而是**在阈值之下等待**。
2. **唤起**——价值本体被触碰，切入发生。方面从潜在切片成为在场切片：对象本体展开，行动本体具备执行的可能。唤起是切片被"切出"的瞬间。
3. **展开**——方面在对象本体划定的视域内执行行动本体：读、改、拦、放。这是实践密度最高的阶段，它与其视域中的存在者打交道，持续一段，直到完成标准达成。
4. **完成**——行动本体所定义的完成标准达成（"怎么算做完"由此显式化）：拦下了一次越权动作、写入了一段经验、放行了一次调用。完成是展开的终止点。
5. **交还与退出**——产物/效应交还实践场域：推进驱力循环、改变场域状态、或留下痕迹。随后方面退出在场，回落到潜伏，等待下一次价值触碰。

**生命周期的性质：**

- **循环**：一个方面在一次实践中可多次被唤起——安全方面每次行动前都展开。
- **嵌套**：多方面生命周期交错——记忆方面可能在多个其他方面完成时被唤起。
- **留痕**：每次"唤起 → 退出"都留下可观测的痕迹，供审计回看——这正是方面方面提供视角的地方。
- **可进化**：唤醒条件（价值本体）、展开深度（对象本体）、完成标准（行动本体）都在生命周期中随实践历史被修订。

生命周期与结构要素的映射：

| 生命周期阶段 | 由哪个结构驱动 |
|---|---|
| 潜伏 | 价值本体（唤醒条件） |
| 唤起 | 价值本体被触碰，切入发生 |
| 展开 | 对象本体视域 ＋ 行动本体的展开行动 |
| 完成 | 行动本体的完成标准 |
| 交还与退出 | 行动本体的交付行动 |

### 对象本体的实体化与留存

**实体化不是创造物质，而是赋形。** 物质（原始数据、字节流、文本、外部状态）始终在实践场域底部——无差别、流动、未被理解。对象本体不是"词典"，而是一套**赋形规则**，它规定三件事：什么物质进入视域（在场）、这些物质以什么方式被理解（存在方式）、什么不进入视域（留白）。

当方面唤起并展开，其对象本体像一束光扫过场域：无差别的物质在这一刻被**收拢、成形、获得边界与身份**——原始文本被实体化为"待审查的敏感信息"，字节流被实体化为"待校验的参数"，一次交互被实体化为"待记忆的经验"。

两个推论：

1. **实体化是视角性的。** 同一物质，在不同方面的对象本体下被实体化为不同存在者——安全方面把一段文本实体化为"风险"，文档方面把同一段文本实体化为"待排版段落"。存在者必然带着其方面的面向烙印。
2. **实体化产物有瞬时性。** 它活在方面展开期间，随方面退出而可能消解。

实体化产物分三层，命运不同：

| 层 | 内容 | 命运 |
|---|---|---|
| 瞬时态 | 只服务于本次展开的存在者（如"本次调用的风险判断"） | 随方面退出**消解**，不保存 |
| 效应态 | 已改变场域状态本身（拦下动作、放行调用、改了一处文档） | **无需另存**——改变已刻入场域 |
| 留存候选 | 对后续实践有价值（一段被识别出的经验、可复用的结论） | **交还**，交由记忆方面裁决 |

**关键：方面不自己决定保存。** 这呼应"方面不做'事'"——保存是记忆方面的职责。方面在"交还与退出"阶段，只负责把留存候选**显式标记**并交还场域；由记忆方面（作为独立方面）在唤起时裁决：留、弃、还是转化。

**记忆方面的判据**：**是否改变未来决策**。改变决策的高频进工作记忆，低频归档，冲突标版本；不改变决策的不留。

**底线不丢：** 无论保存与否，审计痕迹都记录"曾实体化过什么、以何种方式展开"——这是可观测性原则兜底。

一句话：**物质经对象本体赋形而实体化；瞬时态消解、效应态刻入场域、留存候选交还记忆方面裁决——方面只管标记，不自己保存。**

### 行动本体：展开与交付

行动本体不可能只是"做事"，它必须同时**把做出来的东西交出去**。因此：

**行动本体 = 展开行动 ＋ 交付行动**（这是最小集，不排除更多）

| 行动 | 朝向 | 内容 | 对应生命周期 |
|---|---|---|---|
| **展开** | 对内 | 在对象本体视域内处理存在者：读 / 改 / 拦 / 放 | 展开阶段 |
| **交付** | 对外 | 把产物交还实践场域：瞬时态消解、效应态留下、留存候选**显式标记**并交还记忆方面 | 交还与退出阶段 |

两者的分工本质上是**"处理世界"与"归还世界"**的分野：

- **展开**是实践密度最高的行动——方面与其视域中的存在者打交道，完成它的本职工作。
- **交付**是方面责任感的落点——它不私藏产物，而是把该消解的消解、该留下的留下、该交还的**标记清楚**交给裁决方（记忆方面），并且全程留痕给审计。

由此，行动本体的完整定义：

> **行动本体**：方面展开与交付的方式。展开——在对象本体视域内对存在者执行读、改、拦、放；交付——将产物交还实践场域：瞬时态消解、效应态刻入场域、留存候选显式标记后交还记忆方面裁决。

### 方面方面的运作

1. **方面契约 = 元结构的颁布。** 要求任何方面声明四要素、满足两个不变量——这不是工程约定，而是方面方面对一切方面的**构成性规定**。
2. **自我指涉。** 方面方面自身也是一个方面，也必须满足元结构：它的面向是实践的结构本身（因此它叫方面方面）；价值本体是——它朝向"实践的自觉"这一价值，在主体自我反思时被激活；它的对象本体是——视域中的存在者即"方面"本身（切片、契约、实践的结构），它把世界理解为**由方面构成的世界**，不把具体情境内容纳入视域，故不代行任何具体方面；行动本体是颁布与修订契约。
3. **自我修订。** 契约的修订只能在自我意识中发生：由主体以反思方式介入，门槛高于一般方面；且修订只改变"如何切分"，不触及硬红线。
4. **与核心的关系。** 核心是空的驱力循环，提供实践推进的动力；方面方面提供实践展开的形式。审计记录，正是从方面方面的视角看出去的实践。

> 一句话：方面方面，是框架对自己的切片；它颁布方面的元结构，约束自身的修订，让主体的实践既是展开的，又是被理解着的。
